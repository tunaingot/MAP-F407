# MAP-F407の概要
**AUDIO & MIDI PLAYER MAP-F407**はWAVファイル、Standard MIDI Fileの再生専用機で、以下のような機能があります。

- フロントパネルの操作でファイル選択・再生・停止
- リアパネルに搭載した端子台の接点入力でファイル選択・再生・停止
- 素材(WAVファイル、Standard MIDI File)はUSBメモリに格納
